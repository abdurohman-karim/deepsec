# DeepSec

Личный «антивирус», который охраняет сессии Telegram Desktop (`tdata`) от стилеров. Сам завершает украденную
сессию, даже если вы офлайн, и обо всём сообщает в Telegram-бота с inline-меню.

## Почему это важно

Стилеры (Lumma, RedLine, Vidar и десятки «граберов») просто копируют папку `tdata`. Этого достаточно,
чтобы открыть ваш аккаунт на другом компьютере — **облачный пароль (2FA) не спасает**, потому что
вор получает уже авторизованный сеанс, а не логинится заново.

## Из чего состоит

```
 Windows-ПК                                         Сервер (/home/bots/deepsec)
┌───────────────────────────────┐   WebSocket +    ┌───────────────────────────────────┐
│ Агент (SYSTEM)                │   TLS, отпечаток │ Хаб агентов                       │
│  журнал Security → детектор   │ ───────────────▶ │ Ядро: тревоги, блокада, «не на    │
│  kill / брандмауэр / блок ПК  │ ◀─────────────── │       связи»                      │
│  очередь, если нет сети       │     команды      │ Сторож (Telethon) ── завершает    │
└───────────────────────────────┘                  │       сеансы аккаунта             │
                                                   │ Бот aiogram ── inline-меню вам    │
                                                   └───────────────────────────────────┘
```

**Агент на Windows** — только то, что нельзя сделать удалённо:

1. **Аудит чтения файлов.** Setup включает аудит файловой системы и вешает SACL «Чтение данных» на `key_datas`
   и файлы аккаунтов в `tdata`. При каждом чтении Windows пишет событие 4663 с путём exe и PID.
2. **Белый список по подписи.** Читать tdata можно только `Telegram.exe` с валидной подписью Telegram FZ-LLC
   (и Защитнику Windows). Вирус, переименованный в `Telegram.exe`, подпись не подделает.
3. **Ловушки.** В `%APPDATA%` — фейковые `tdata` от AyuGram / Kotatogram / 64Gram, их ищут стилеры.
4. **Реакция за миллисекунды:** процесс и его дети убиваются, exe получает запрет сети в брандмауэре.
5. **«Кто-то подключился»:** RDP, входы и разблокировки Windows, подбор пароля, AnyDesk / TeamViewer / RMS и др.
6. **Самопроверка:** агент сам читает canary-файл и ждёт событие; тревога, если аудит отключили или журнал очистили.

**Сервер** — рядом с остальными ботами:

1. **Сторож** — отдельный сеанс вашего аккаунта. При краже `tdata` он сам завершает все сеансы, кроме
   доверенных ⭐ (ваш телефон), и на 24 часа включает **блокаду**: любой новый вход сразу завершается.
   Сторож на сервере, а не на ПК: он сработает, даже если компьютер заражён или выключен.
2. **«Компьютер не на связи»** — если агент молчит дольше 3 минут (выключили ПК или остановили агента).
3. **Бот** — одна команда `/menu`, дальше только кнопки. Одно «живое» сообщение меню редактируется,
   ваши сообщения удаляются. Тревоги приходят отдельными сообщениями с кнопками: «📵 Завершить сеансы»,
   «🔪 Убить», «🧱 Без сети», «📦 Карантин», «🔒 Блок. экран», «🌐 Отрезать сеть». Принятые меры дописываются
   прямо в тревогу.
4. **🔑 Код подтверждения.** Всё, что ослабляет защиту (выключить авто-реакцию, вернуть сеть, снять блокировку,
   доверять программе или сеансу, снять блокаду), требует код из приложения-аутентификатора. Если украдут
   ваш Telegram, вор не сможет выключить защиту. Подбор кода сам считается кражей — сеансы завершаются.

## Сервер

С вашего компьютера, из папки проекта:

```bash
./deploy.sh root@IP_СЕРВЕРА
```

На Windows запускайте из **Git Bash** (правый клик по папке → «Open Git Bash here»), а не двойным щелчком и
не `.\deploy.sh` из PowerShell — так он откроется без адреса и сразу закроется. Пароль SSH спросят несколько раз.

Скрипт копирует проект в `/home/bots/deepsec`, ставит зависимости и службу `deepsec-bot` — так же, как у
`fundraising` и `airopost`. При первом запуске он:

- создаёт `.env` и генерирует `AGENT_TOKEN` и `TOTP_SECRET` — **секрет TOTP добавьте в аутентификатор на
  телефоне** (Aegis, Google Authenticator, 2FAS) и сохраните офлайн, второй раз он не показывается;
- создаёт свой TLS-сертификат и печатает его отпечаток, порт и `AGENT_TOKEN` — они нужны агенту;
- останавливается и просит вписать `BOT_TOKEN` (**отдельный бот** от @BotFather) и `OWNER_ID`:
  `nano /home/bots/deepsec/.env`, затем `./deploy.sh` ещё раз.

Сторож: впишите `TG_API_ID` / `TG_API_HASH` с [my.telegram.org](https://my.telegram.org) → API development tools
и войдите. По умолчанию — по QR-коду: он появится в терминале, на телефоне откройте Настройки → Устройства →
«Подключить устройство» и наведите камеру (код входа сторонним приложениям Telegram часто не доставляет).
Если включён облачный пароль, его спросят после сканирования:

```bash
./deploy.sh root@IP_СЕРВЕРА login
```

Порт агентов — `LISTEN_PORT` в `.env` (по умолчанию `8443`). Если он занят другой программой (например, Apache) или закрыт `ufw`, скрипт предупредит.
Логи: `journalctl -u deepsec-bot -f`. `.env` и `data/` (сеанс сторожа, журнал, сертификат) при обновлении
не трогаются.

## Агент на Windows

Нужны Windows 10/11 x64 и Telegram Desktop с telegram.org (версия из Microsoft Store пока не поддерживается).

### Установщик (рекомендуется)

1. Скачайте `DeepSecSetup-<версия>.exe`: GitHub → Actions → «Windows installer» → последний запуск →
   артефакт `DeepSecSetup` (а для тегов `v*` — во вкладке Releases).
2. Запустите Telegram Desktop, затем установщик (он попросит права администратора).
3. На странице «Подключение к серверу» введите адрес, порт (`LISTEN_PORT` на сервере), отпечаток сертификата
   и `AGENT_TOKEN` — их напечатал `./deploy.sh`. Если токен потерялся:
   `ssh root@СЕРВЕР grep AGENT_TOKEN /home/bots/deepsec/.env`.
4. Откроется окно настройки: найдёт `tdata`, проверит подпись `Telegram.exe`, создаст ловушки, включит аудит
   и автозапуск от SYSTEM. Если всё прошло — «✅ Готово», нажмите Enter.

В меню «Пуск» → DeepSec: «Настроить DeepSec» (повторить настройку, например если Telegram не был запущен),
«Проверить DeepSec» и «Удалить DeepSec». Удаление убирает задачу, правила брандмауэра, изоляцию сети,
ловушки и настройки. Обновление — просто запустите новый установщик, поля сервера можно оставить пустыми.
Чтобы сменить только порт, введите при обновлении один порт — адрес останется прежним.

Установщик не подписан цифровой подписью, поэтому SmartScreen покажет «Неизвестный издатель»:
«Подробнее» → «Выполнить в любом случае».

Собрать установщик самому (на Windows): `powershell -ExecutionPolicy Bypass -File packaging\build.ps1`.

### Из исходников

1. Положите проект туда, куда без прав администратора писать нельзя: агент работает от SYSTEM,
   и код в папке пользователя вирус мог бы подменить. Нужен Python 3.11+.
   ```powershell
   # PowerShell от имени администратора
   git clone <repo> "C:\Program Files\DeepSec"
   cd "C:\Program Files\DeepSec"
   py -3.12 -m venv .venv
   .venv\Scripts\pip install -r requirements-agent.txt
   ```
2. Запустите Telegram Desktop и выполните setup (от администратора) — он спросит данные сервера:
   ```powershell
   .venv\Scripts\python -m deepsec setup
   ```

### После установки

1. В боте `/menu` → появится компьютер → «🧪 Самопроверка» — должно быть «аудит работает».
2. `/menu` → «📱 Сеансы» → ваш телефон → «⭐ Доверять». Тогда при краже завершится всё, кроме телефона,
   и вы не потеряете доступ к аккаунту. Без доверенных завершаются все сеансы — для входа понадобятся
   SMS-код и облачный пароль.

Диагностика: «Проверить DeepSec» в меню «Пуск» (или `python -m deepsec check`). Лог: `C:\ProgramData\DeepSec\agent.log`.
Агентов может быть несколько — каждый компьютер появится в меню отдельно.

### Проверка «боевой» реакции

Изобразите стилер копией безобидной утилиты — агент убьёт её и запретит ей сеть (саму `powershell.exe` или
`python.exe` для теста не используйте: им тоже запретят сеть):

```powershell
copy C:\Windows\System32\certutil.exe $env:TEMP\stealer-test.exe
& $env:TEMP\stealer-test.exe -hashfile "$env:APPDATA\AyuGram Desktop\tdata\key_datas"
```

Придёт тревога «Кто-то читает файлы-ловушку tdata». Снять блокировку: меню компьютера → «🧱 Блокировки».

### Скриншот и список программ

В меню компьютера: «📸 Скриншот» присылает снимок всех мониторов с подписью — пользователь Windows, активное
окно и сколько времени не трогали мышь и клавиатуру. «📋 Что запущено» показывает открытые окна с заголовками
и фоновые программы (без процессов самой Windows). Агент на время запроса запускает себя в сеансе того, кто
сейчас за компьютером, и сразу завершает; если экран заблокирован или никто не вошёл, бот так и ответит.
Каждый запрос записывается в `agent.log`. На экране компьютера снимок никак не обозначается — если ПК
пользуются другие люди, предупредите их, что он под присмотром.

### Глаз на экране

Меню компьютера → «👁 Глаз на экране»: пиксельный «Большой глаз» на фоне тёмно-красных лучей в правом нижнем
углу, с надписью. Настроения: 👀 следит (медленно водит взглядом за курсором, «Katta og'a seni kuzatyabdi»),
😏 ухмыляется, 😠 злится (зрачок-щель, красные прожилки, дрожит), 😴 дремлет (иногда приоткрывается и
подсматривает) — или «✏️ Свой текст» до 60 символов. Окно поверх всех, клики проходят сквозь него, фокус оно
не забирает, поэтому игре не мешает; через 2 часа исчезает само, «🙈 Убрать» — сразу. Поверх игр в
эксклюзивном полноэкранном режиме Windows рисовать не даёт — глаз виден в оконном режиме и «без рамки».
Надписи по умолчанию — `PET_TEXTS` в `deepsec/protocol.py`.

## Ограничения (честно)

- Это обнаружение и реакция, а не запрет: Windows сообщает о чтении **после** открытия файла. `key_datas`
  маленький — стилер успеет его прочитать. Поэтому главное — сразу завершить украденный сеанс.
- Если вирус внедрится в сам `Telegram.exe` или получит права администратора — он может обойти агента
  (но отключение аудита, очистка журнала или пропавший агент вызовут тревогу).
- Telegram позволяет завершать чужие сеансы только сеансу **старше 24 часов** — первые сутки после
  `./deploy.sh … login` автозавершение не сработает (бот предупредит).
- `data/guard.session` на сервере — полный доступ к аккаунту; защищайте сервер (SSH по ключу).
  Кто управляет сервером, тот управляет и агентами.
- «Завершить все другие сеансы» с телефона отключит и сторожа — потом снова `./deploy.sh … login`.

## Что ещё обязательно сделать

1. **Локальный код-пароль в Telegram Desktop** (Настройки → Конфиденциальность → Код-пароль). Он шифрует
   `tdata` — украденная копия без него бесполезна. Это самая сильная мера из всех; пароль — длинный.
2. **Облачный пароль (2FA)** — защищает от входа по SMS-коду.
3. **Автозавершение неактивных сеансов** — Настройки → Устройства → «Если сеанс неактивен» → 1 неделя.
4. Не запускайте кряки, «читы», «бесплатный софт» — основной путь заражения стилерами.

## Разработка

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt -r requirements-agent.txt pytest
.venv/bin/pytest
```

Серверный код — Python 3.10+ (`deepsec/server`, общие `incidents.py`, `state.py`, `protocol.py`, `totp.py`),
агент — 3.11+. Логика тестируется на любой ОС, включая настоящий WebSocket между агентом и сервером;
Windows-специфичное (`monitors/eventlog.py`, `response.py`, `winacl.py`, `setup_win.py`) — только на Windows.
